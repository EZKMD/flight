# V0.1 validation matrix

V0.1 has been exercised with deterministic tests, mock fixtures, and live manual
observations. Real flights are historical examples only: provider data changes,
and none of these designators is hard-coded or converted into a fixture.

| Case | Result | What it verified |
| --- | --- | --- |
| Cruising | Validated | Fresh airborne telemetry with neutral vertical rate produces `LIVE` and telemetry-derived `CRUISING`. |
| Climbing | Validated | Fresh vertical rate beyond the climb threshold produces telemetry-derived `CLIMBING`. |
| Descending | Validated | Fresh negative vertical rate beyond the descent threshold produces telemetry-derived `DESCENDING`. |
| Boarding | Validated | A resolved occurrence inside the pre-departure window displays `SCHEDULED` with the `BOARDING` phase and no false live claim. |
| Scheduled | Validated | A future occurrence remains schedule-only and does not request meaning from absent telemetry. |
| Landed | Validated | Provider/arrival evidence produces `LANDED`, zero remaining time, and completed progress. |
| Active without telemetry | Validated | A coherent active occurrence remains `TRACKING` and provider-confirmed `AIRBORNE`; missing OpenSky data is not presented as live. |
| Full live path | Validated | Commercial designator → occurrence/leg → ICAO24 → fresh OpenSky state → `LIVE` → telemetry phase → geospatial progress → renderer. |

Historical manual checks during V0.1 development included BA281, QR905, LS802,
VN778, EK409, and VA356. These examples collectively exercised the matrix but
must not be expected to reproduce the same state later.

## Automated regression coverage

`make test` covers occurrence selection, leg isolation, airport validation,
designator classification, exact ICAO24 matching, freshness transitions, phase
thresholds/hysteresis, duration rules, progress provenance/geographic edge
cases, telemetry-history contracts, visual dispatch contracts, and every mock
fixture.

## Manual release checklist

```sh
make clean
make
make test
./flight --version
./flight --help
./flight QF9 --fixture cruising
```

For the interactive fixture, verify resize behavior, `r`, fixture-only `f`, `q`,
and terminal restoration. Live-provider checks are manual so automated testing
does not consume quota.
